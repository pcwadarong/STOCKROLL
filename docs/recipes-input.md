# 레시피 수치 입력

각 레시피의 **값** 칸을 채워주세요. 모르는 칸은 비워두면 됩니다 — 빈 칸은 추정해서 채우지 않고 '미입력'으로 저장합니다.

- 선택지는 X-T50 메뉴 기준으로 적었습니다. 카메라에 보이는 표기와 다르면 카메라 표기를 그대로 적어주세요.
- 레시피를 안 쓰기로 했으면 제목 옆에 `(제외)`라고 적어주세요.
- 목록에 없는 레시피는 맨 아래 빈 양식을 복사해 추가하세요.

## -1. 기본 세팅

컬러스페이스 sRGB 회절현상 보정 on 장노출 노이즈 리덕션 on 선명도 -2 고감도 노이즈 감소 -4 샤프니스 -2 색농도 0 톤곡선 H-2 S-2, 다이나믹레인지 화이트발란스 auto 피부보정 off 컬러크롬 fx블루 dir, 컬러크롬 강, 그레인 strong small, 이미지크기 L 3:2 화질 F+RAW JPEG
기본이 조리개 A모드이고 iso, 셔터스피드는 자동
단, 보통 이중에 한 개 골라서 사용함(상황에 따라)
1 - 기본 감도 125 최대감도 6400 최소셔터속도 1/125 (동적인, 반려동물 아이들 걷는 사람 등)
2 - 기본 감도 125 최대감도 6400 쵣소셔터속도 1/250 (적당한 일상스냅)
3 - 기본 감도 125 최대감도 3200 쵣소셔터속도 1/60 (정적인, 풍경)
